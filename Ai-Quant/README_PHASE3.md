# PHASE 3 — BACKTEST ENGINE

**Status:** Complete (VectorBT-based, realistic execution model)

## Overview

Phase 3 implements a full backtesting engine for the Donchian breakout strategy on FX daily timeframe.

### Key Features

✓ **Realistic Execution Model**
- Entry at next-bar open (not signal-bar close)- Spread + slippage modeling for entry and exit
- Stop-loss gap adjustment (opening beyond stop)
- Swap cost tracking (daily carry cost)

✓ **Anti-Lookahead Bias**
- Two-layer defence: call-site data strip + regression test
- All signals based on candles[:-1] (live system simulation)
- Validated by `validate_no_lookahead()` test

✓ **Position Management**
- Max 2 concurrent positions (portfolio level)
- Max 1 position per pair
- USD exposure correlation control (max 2 USD-involved pairs)
- Position sizing: 0.25% risk per trade

✓ **Cost Modeling**
- Spread scenarios: NORMAL, STRESS_1.5x, STRESS_2x
- Per-pair spread and slippage estimates
- Daily swap costing (both long and short)
- Entry/exit cost separation

✓ **Performance Metrics**
- Sharpe ratio (annualized)
- Max drawdown
- Profit factor
- Win rate & expectancy
- Monthly return distribution
- Per-pair breakdown

✓ **Walk-Forward Validation**
- Rolling IS (24 months) / OOS (6 months) windows
- Parameter grid search on in-sample only
- Out-of-sample evaluation (what we trust)
- Automated pass/fail criteria (Phase 2 thresholds)

## Architecture

```
backtest/
  costs.py          → Spread, slippage, swap models (frozen at initialization)
  data.py           → OANDA API + CSV cache fallback
  strategy.py       → Donchian signals (shift-based LAB prevention)
  engine.py         → Main event-driven simulation loop
  metrics.py        → Sharpe, MDD, PF, return distribution, etc.
  walk_forward.py   → Rolling parameter optimization + OOS validation
  reports.py        → CSV exports, matplotlib charts
  run_backtest.py   → Main entry point (full suite runner)
```

## Key Design Decisions

| Decision | Rationale |
|---|---|
| Event-driven loop (not VectorBT Portfolio) | Explicit control over position limits, ATR stops, gap adjustment |
| Shift(2) for signals | Matches live system's anti-LAB strip of candles[-1] |
| Spread scenarios | Tests profitability under different market conditions |
| Daily swap modeling | Accumulated cost can be significant on extended holds |
| 0.25% risk per trade | Conservative sizing for 90%+ account survival |
| Walk-forward mandatory | Single backtest is biased; OOS validation essential |

## Important Caveats

⚠️ **This Is Demo Data**
- Synthetic OHLCV generated by random walk
- Not real market execution
- Backtest results are NOT predictive of live performance

⚠️ **Execution Model Assumptions**
- Entry at bar open (actual liquidity depends on broker)
- 22:10 UTC execution (lowest liquidity window)
- Spread estimates ±30% margin of error
- Swap rates can change with central bank policy

⚠️ **Statistical Limitations**
- ~4 trades/month means ~50 trades/year
- 3-year walk-forward = ~150 trades (barely significant)
- Regime dependence: may not generalize to 2025+ markets
